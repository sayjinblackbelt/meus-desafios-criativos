# Metodologia do projeto

## 1. Entender o desafio

Registrar o problema proposto e o resultado esperado.

## 2. Definir a intenção

Responder: o que a IA deve produzir, para quem e com qual finalidade?

## 3. Adicionar contexto

Descrever cenário, dados disponíveis, critérios e limitações.

## 4. Refinar a instrução

Organizar papel, objetivo, contexto, dados, instruções, formato e restrições.

## 5. Produzir o artefato

Salvar o resultado em formato Markdown ou outro formato adequado.

## 6. Versionar

Publicar no GitHub e utilizar commits para registrar a evolução.

## 7. Registrar aprendizados

Documentar conceitos técnicos relacionados e conexões com outros projetos.

## 8. Evoluir

Novos desafios devem ampliar progressivamente a complexidade técnica e a capacidade de aplicação prática.
