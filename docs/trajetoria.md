# Trajetória do projeto

## 2026-09-22 — Início

O repositório `meus-desafios-criativos` foi criado para reunir desafios práticos de aprendizagem.

## 2026-09-22 — Primeiro desafio

Foi desenvolvido o desafio de análise de feedback de clientes bancários. O exercício propôs construir um prompt em três etapas: intenção; contexto e restrições; união e refinamento.

## 2026-09-22 — Primeiro artefato versionado

O prompt final foi publicado em Markdown e posteriormente reorganizado dentro de uma estrutura específica para o desafio.

## Expansão da trilha de aprendizagem

No mesmo período de estudos, foram trabalhados conceitos relacionados a dados e bancos relacionais, incluindo:

- SQL;
- MER e DER;
- bancos de dados relacionais;
- chaves primárias;
- cardinalidade;
- normalização;
- subconsultas;
- JOINs;
- execução de scripts;
- Views;
- seeds;
- migrations automatizadas com PowerShell;
- ETL;
- Excel e Power Query;
- uso de IA/Copilot para apoiar consultas SQL.

Esses conhecimentos fazem parte do contexto de formação e poderão gerar novos desafios e artefatos no repositório.
