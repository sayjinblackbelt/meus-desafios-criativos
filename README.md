# Meus Desafios Criativos

Repositório destinado ao registro, organização e versionamento dos desafios práticos desenvolvidos durante minha trajetória de aprendizagem em **Inteligência Artificial, Engenharia de Prompt, Dados e Tecnologias aplicadas à análise de informação**.

O projeto começou a partir dos desafios criativos do **Bootcamp Bradesco - GenAI, Dados & Cyber**, realizado na DIO, e evolui como um portfólio de aprendizagem prática.

## 🎯 Objetivo

Documentar não apenas os arquivos finais dos desafios, mas também a trajetória de construção: contexto, intenção, critérios, decisões, versões e aprendizados.

A proposta é transformar cada exercício em um artefato reutilizável e demonstrável no portfólio profissional.

## 🧭 Trajetória atual

1. **Início do repositório** — criação do espaço para reunir os desafios.
2. **Desafio de Engenharia de Prompt** — construção de um prompt para análise de feedbacks de clientes bancários com apoio de IA.
3. **Definição da intenção** — identificação do que analisar, para quem e para qual finalidade.
4. **Contexto e restrições** — definição dos dados disponíveis, critérios e cuidados com dados sensíveis.
5. **Refinamento do prompt** — consolidação das etapas em uma instrução estruturada e acionável.
6. **Versionamento no GitHub** — publicação do resultado em Markdown.
7. **Ampliação do registro** — documentação da evolução do aprendizado em IA, SQL, bancos relacionais, modelagem de dados, automação, migrations, seeds, views e ETL.

## 🧠 Trilha de conhecimentos relacionada

Durante a construção deste projeto, a trajetória de aprendizagem passou também por:

- Banco de dados relacionais;
- MER e DER;
- SQL;
- `SELECT`, `JOIN`, subconsultas e funções de agregação;
- chaves primárias e relacionamentos;
- cardinalidade;
- normalização (`1NF`, `2NF`, `3NF`);
- execução de scripts SQL;
- Views;
- Seeds (*generate seeds*);
- migrations automatizadas com PowerShell;
- ETL (*Extract, Transform, Load*);
- Excel e Power Query;
- uso de IA/Copilot para apoiar a escrita de consultas SQL;
- Engenharia de Prompt aplicada à análise de dados e feedbacks.

## 🔬 Princípios do projeto

- **Aprender fazendo:** cada conceito deve, sempre que possível, resultar em um artefato.
- **Documentar a trajetória:** registrar o processo, não apenas o resultado.
- **Versionar:** utilizar Git/GitHub para acompanhar evolução e histórico.
- **Evidência antes de conclusão:** separar fatos observados de interpretações.
- **Privacidade:** evitar exposição de dados pessoais ou sensíveis.
- **Reutilização:** produzir materiais que possam servir como referência para projetos futuros.
- **Progressão:** ampliar gradualmente a complexidade técnica.
